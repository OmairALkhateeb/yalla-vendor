# Yalla Vendor Hub

Create a complete web-based Arabic RTL UI/UX for a Restaurant / Vendor Panel in a multi-service Super App called Yalla.

This is a Vendor-Multi system where each restaurant or store manages its own operations.

This is NOT a marketing dashboard.

This is an operational system.

Main responsibilities of the vendor panel:

- manage orders

- accept or reject requests

- update order status

- manage menu (categories, items, add-ons)

- track performance

- manage financial data and wallet

Design priorities:

- clarity

- speed

- operational efficiency

- clean structure

- strong hierarchy

- professional business UI

The system should feel like a real SaaS product used daily by restaurants.

Please:

1. create full information architecture

2. create full layout (sidebar + content)

3. define navigation

4. define all modules

5. design all screens

6. define reusable components

7. create realistic Arabic content

Use RTL layout and professional modern UI.


I want arabic english , kurdish white mode dark mode and the primary color 0xFFE62020
